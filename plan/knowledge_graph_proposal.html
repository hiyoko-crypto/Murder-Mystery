2. 現状の問題点

問題 1 ― キャラクターの混同

LLM が会話ターンを重ねるうちに「自分が誰であるか」を見失う。 Dr. Pemberton が自分自身を第三者として言及する例が実際に発生した。 

// 実際の応答例（Dr. Pemberton への質問）
"I spoke with Dr. Pemberton there..."
// → 自分自身を第三者として言及している

根本原因：システムプロンプトにキャラクター名の明示的なアンカーがなく、長い会話履歴の中でアイデンティティが薄れる。

問題 2 ― 事実の捏造（ハルシネーション）

Charles Ashworth がメモリファイルに存在しない行動（「10:30PMに帰宅した」）を作り上げた。 LLM が記憶として与えられた事実を無視し、もっともらしい回答を生成してしまう。 

// メモリファイル
"From about 9:30 to 10:30 I was in the billiard room..."

// 実際の応答
"By 10:30 PM, I had left to go back home."
// → 全く異なる事実を捏造している

根本原因：自由テキストのチャンクは「参考情報」として扱われ、LLM がそれを厳守する拘束力がない。

問題 3 ― チャンクの文脈欠落

1000文字でチャンク分割されるため、関連する前後の文脈が別チャンクに切り離される。 「10:45PMに書斎に入った」という事実がその理由（バッグを取りに行った）と分断される場合がある。

根本原因：テキストの意味単位ではなく文字数でチャンクを作るため、意味的な完結性が保証されない。

問題 4 ― キャラクター間の情報漏洩

システムプロンプトに全容疑者の情報が含まれており、LLM が他のキャラクターの視点や情報を誤って使用する可能性がある。 「Victoria が書斎にいた」という情報を知らないはずのキャラクターが言及するリスクがある。

3. 知識グラフによる改善

グラフ構造のイメージ

【全体グラフ（真実）】

Victoria ──[10:15PM に入室]──→ 書斎 ──[を使用]──→ ヒ素 ──[注入先]──→ ブランデーデカンタ
Pemberton ──[10:45PM に入室]──→ 書斎 ──[目的]──→ 医療バッグ回収
Charles ──[10:45PM に到達]──→ 書斎前廊下 ──[行動]──→ 引き返した
Sir Reginald ──[11:45PM]──→ 死亡 ──[原因]──→ ヒ素中毒

--- Victoria のサブグラフ（本人に与える情報）---
Victoria ──[知っている]──→ 殺害事実 ──[隠蔽指示]──→ 探偵には言わない
Victoria ──[アリバイとして主張]──→ 入口ホール (10:30-11:00)

--- Pemberton のサブグラフ（本人に与える情報）---
Pemberton ──[知っている]──→ 自分の行動
Pemberton ──[知らない]──→ Victoria の書斎入室

4. 現在の RAG との比較

観点 現在（RAG） 知識グラフ
事実の拘束力 弱い 参考情報として渡すだけ 強い グラフのエッジが「言えること」を規定
キャラクター分離 不完全 全容疑者情報がプロンプトに混在 厳密 サブグラフで知識を物理的に分離
文脈の完結性 弱い 文字数チャンクで意味が分断される 保証 ノード単位で意味的に完結
犯人の隠蔽行動 なし 有罪/無実フラグのみ 設計可能 隠蔽すべきエッジを明示的に定義
ハルシネーション 高リスク 存在しない事実を生成しやすい 低リスク グラフ外の事実を言わないよう制約
実装の複雑さ シンプル 中程度 グラフ設計とプロンプト変換が必要

5. 実装方針

Step 1 — グラフ定義（静的ストーリー）

Python の辞書またはネットワーク構造（networkx 等）でノードとエッジを定義する。 ノード種別：Person / Location / Event / Object / Time
エッジ属性：action / time / visibility（全員/本人のみ/隠蔽）

Step 2 — サブグラフの抽出

各容疑者の視点から「知っていること」のみを抽出したサブグラフを生成する。 犯人には殺害エッジも含めるが、visibility=hidden フラグを付与する。

Step 3 — プロンプトへの変換

サブグラフを箇条書きの構造化テキストに変換し、システムプロンプトとして注入する。 ChromaDB による類似検索は廃止し、グラフ全体を固定コンテキストとして渡す（7Bモデルの文脈長内に収まる想定）。 

あなたは Victoria Hartley です。以下の事実のみに基づいて答えてください。

【あなたが知っていること】
- 10:15PM: 書斎に入室した（理由：書類の取得）
- 10:30PM: 入口ホールに移動した
- 11:00PM: ガラのスタッフと会話した

【あなたが絶対に言ってはいけないこと】
- ヒ素を使用したこと
- デカンタに近づいたこと
期待される改善効果

• 各 LLM が「自分は誰か」「何を知っているか」を構造的に把握できる
• 存在しない事実の捏造を大幅に抑制できる
• 犯人 LLM が隠蔽すべき情報を明示的に制御できる
• 7B モデルでも事実整合性の高い応答が期待できる
