Reasoned Indictment Design

作成日: 2026-06-23 | 対象: 理由付き犯人指名 | 方針: 自由文をKG edgeへ写像し、proof graphでルール判定

1. 方針

プレイヤーは犯人を選ぶだけでなく、自由文で理由を入力する。 LLMは採点者ではなく、理由文に含まれる知識グラフedgeを抽出する役割だけを持つ。 勝敗は solution.proof_graph の必須グループ、重み、最低スコアでルールベース判定する。

Accuse容疑者選択
→
Reason自由文
→
Extractedge ID抽出
→
Scoreproof graph
→
Verdict勝敗

2. Proof Graph

solution に自然文rubricではなく、KG edge groupで構成された proof_graph を追加した。 全グループ必須ではなく、必須グループ + 重み付きスコアで柔軟に判定する。 

"proof_graph": {
  "minimum_score": 4,
  "groups": [
    {
      "id": "compact_link",
      "edge_ids": ["e7", "e18"],
      "min_required": 2,
      "weight": 4,
      "required": true
    },
    {
      "id": "vent_route",
      "edge_ids": ["e8", "e9"],
      "min_required": 2,
      "weight": 2,
      "required": false
    },
    {
      "id": "locked_room",
      "edge_ids": ["e6"],
      "min_required": 1,
      "weight": 1,
      "required": false
    }
  ]
}
現在の勝利条件は、犯人が正しいこと、compact_link が成立すること、合計スコアが4以上であること、重大な捏造がないこと。

3. Edge Extraction

modules/reason_edge_extractor.py が、プレイヤーの理由文を原子的な主張へ分解し、 それぞれをKG edgeへ対応付ける。ここでは勝敗判定はしない。 以前のような脚本固有の単語ヒューリスティックは持たず、KGのnode名、表示名、説明、significance、edge relation、edge detailを材料にLLMが対応付ける。 

{
  "claims": [
    {
      "text": "A compact with Elena's initials was found in the vent.",
      "quote": "通気口に エレナのイニシャルが書いてあるコンパクト"
    }
  ],
  "mentioned_edges": [
    {
      "edge_id": "e7",
      "confidence": 0.93,
      "matched_claim": "The compact was found in the vent.",
      "quote": "通気口に...コンパクト"
    },
    {
      "edge_id": "e18",
      "confidence": 0.88,
      "matched_claim": "The compact belongs to Elena.",
      "quote": "エレナのイニシャル"
    }
  ],
  "contradicted_edges": [],
  "invented_major_claims": []
}

confidence はLLMによる対応付けの確からしさで、現在は 0.6 以上のedgeだけを採用する。 採用済みedgeは互換性のため mentioned_edge_ids にも変換され、後段のproof graph判定へ渡される。

invented_major_claims は、KGにない新しい証拠、証人、アリバイ、犯行方法など、事件の論理を壊す捏造を検出するために使う。

4. Rule Evaluation

modules/indictment_evaluator.py が抽出edgeをproof graphへ照合する。

判定条件
accused_correct accused_node_id == solution.killer_node
reason_accepted 必須グループがすべて成立し、スコアが minimum_score 以上で、重大な捏造がない。
won accused_correct と reason_accepted が両方true。
